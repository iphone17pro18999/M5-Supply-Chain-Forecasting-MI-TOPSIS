# Raw Data

This folder should contain the raw M5 Forecasting Accuracy dataset files.

Required files:

- `calendar.csv`
- `sales_train_validation.csv`
- `sell_prices.csv`

The raw files are not included in this repository because of file-size and redistribution considerations. Download the public M5 dataset from the official competition/data source and place the required CSV files in this folder before running the scripts.
