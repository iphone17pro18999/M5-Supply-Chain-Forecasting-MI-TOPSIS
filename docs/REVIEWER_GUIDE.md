# Editor/reviewer quick verification guide

A reviewer wishing to verify the study can:

1. obtain the three M5 source files from the official Kaggle competition;
2. install the pinned Python environment;
3. run `python run_all.py`;
4. inspect `outputs/generated/reproducibility_audit.json`;
5. compare newly generated results with the compact archived outputs in `outputs/reference/`;
6. regenerate all paper plots using Steps 13–14.

The repository does not require access to the submitted manuscript or Supplementary Material.
